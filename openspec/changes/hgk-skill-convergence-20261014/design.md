## Decisions

- Use immutable pre-image copies and byte-offset spans for original entry sections/rules. Store each original span once in topic payloads with an ordered mapping; generated navigation/headers are distinguishable metadata. Reconstruction consumes candidate payload spans and checks every byte, never returns the pristine baseline as a fake reconstruction.
- Keep original frontmatter and trigger in place. Keep the source-backed control-plane, SoD, refusal and rollback core inline. Move detailed procedures and dated status/history into selected topic references; label history so it cannot masquerade as current policy. Preserve original clauses and alias mapping rather than deleting contradictions.
- Consolidate navigation into stable topic ownership. Retained filename aliases must preserve caller lookup and anchor semantics; aliases count as real physical files and cannot be hidden to game the linter denominator. Keep global reference warning honest if compatibility necessarily retains many aliases.
- Reuse existing lint implementation and mutation locks. Add full-current findings plus evaluation status; preserve existing delta-only `lint_warnings`. Wire through each relevant single/batch mutation caller, and label uncovered direct/install/profile surfaces rather than inventing global enforcement.
- Run separate Codex writers for two skill roots and consumer root. Qualify the actual native workspace-write sandbox against admitted/outside/subprocess/traversal writes before candidate dispatch. No `danger-full-access` fallback.
- Independent GLM VERIFY/SECURITY recompute exact frozen candidates, execute suites and inspect adverse cases. They do not repair. The command token/usage receipt proves transport only; exact-subject strict verdict and actual command output are separately required.
- Apply tooling uses dry-run default, precise allowlist, pre-image comparison, immutable backups, atomic per-file replacement, partial-failure compensation and rollback drift guard. Existing HGK typed APIs own admission and result recording; no second authority engine.

## Risks / Trade-offs

- Hidden reference or inline rule loss → full source span map, reverse byte reconstruction, alias tests and fresh-context trigger/holdout.
- Reference proliferation merely relocated → bounded topic index, no blind all-reference load, honest alias physical denominator.
- Size reduction mistaken for behavior equivalence → deterministic route/refusal/SoD checks plus independent semantic review; remaining model/profile coverage explicit.
- Shared live tree drift → freeze, source checks immediately before apply and rollback; refuse unknown concurrent edits.
- Existing consumers bypassed by direct filesystem writes → enumerate uncovered surfaces and bind this round's apply path; no claim of universal prevention.
- Scope qualification refusal → stop write-bearing lanes, keep raw failed probes and typed checkpoint; no fake completion.

## Migration Plan

Qualify scope; freeze corpus and baseline; generate nonoverlapping candidates; reconstruct and test; freeze generation; independent VERIFY/SECURITY; bounded maker repair and fresh recheck if needed; admit exact local apply subject; dry-run and rollback rehearsal; local apply/readback/cold-start checks; final independent post-apply review and HGK checkpoint/sweep. Any stage failure retains prior evidence and prevents promotion.
