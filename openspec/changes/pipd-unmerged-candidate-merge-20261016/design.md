# Design

| # | 決策 | 理由 | 否決的替代 |
|---|---|---|---|
| D1 | 以 `diff --shortstat` 為「取代性」判準 | 可量測、不靠回合記憶 | 人工閱讀 20 個回合歷史（否決：慢且不可複驗） |
| D2 | 以 `merge-tree --write-tree` 判衝突 | 唯讀、可在裁決階段就斷言 | 真做一次合併再看（否決：會污染工作區） |
| D3 | 明示放行清單排在分類器最前 | 否則名字含 `closeout` 的真候選會被誤判為證據分支 | 純命名啟發（否決：本回合實際會誤判 #18） |
| D4 | 本地合併＋測試後**單一 push** | 高後果寫入先測後推；一次推送可原子回退 | 逐條 API 合併（否決：無法先跑全套測試） |
| D5 | 不關閉 PR、不刪分支 | 超出裁決範圍；托管側狀態交 Owner | 順手清理（否決：擴權） |

## Risks
- 直接推合併提交使托管側 PR 仍為 open → 已揭露並列為 Owner 動作。
- 分母差異：本地 632 passed／20 skipped vs 托管 CI 635 OK／6 skipped → 兩個分母不可互換，已在證據中標明。
