## Why

The repository homepage and the local working surfaces are the first thing an external engineer reads, and they
were the only part of the convergence work that no round had measured. This change records that measurement and
the ruling that follows from it, so the repository front page stops telling a reader less than the evidence
already on disk.

## What Changes

- The repository homepage gains an external-reader appendix: what the mirror is, where the evidence lives, the
  merged-pull-request index with merge commits, the explicit non-claims, and how a stranger re-verifies a claim.
- The homepage status line is refreshed with the 2026-10-16 merge wave, keeping the earlier dated lines as history.
- Remote branches whose pull request is already merged stop being advertised as unfinished work.
- The round's own measurement, receipts and ruling are archived under a single evidence prefix.
