#### SM-05｜Evidence

- **States**：DECLARED → CAPTURED → HASHED → VALIDATED → EXPIRED → REJECTED → ACCEPTED → SUPERSEDED
- **Invalid transition**：reject event, preserve canonical state, emit finding/evidence; never coerce to nearest valid state.
- **Retry**：only explicitly retryable transient events; retry budget=3 unless stricter domain budget; semantic/authority/security failures are non-retryable.
- **Timeout**：active nonterminal state must carry deadline; timeout routes to BLOCKED/EXPIRED/KILLED/REJECTED as appropriate.
- **Requalification**：expiry, revocation, source/version drift or rollback removes prior qualification and requires the corresponding admission path again.

|---|---|---|---|---|
|CAPTURE|DECLARED|CAPTURED|producer/result/effect scope bound|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|HASH|CAPTURED|HASHED|actual bytes/readback available|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|VALIDATE|HASHED|VALIDATED|schema/scope/expiry/verifier checks pass|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|EXPIRE|VALIDATED|EXPIRED|trusted time exceeds expiry|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
