#### SM-02｜TaskLease

- **States**：CREATED → OFFERED → ACCEPTED → ACTIVE → RENEWED → EXPIRED → REVOKED → RETURNED → CLOSED
- **Invalid transition**：reject event, preserve canonical state, emit finding/evidence; never coerce to nearest valid state.
- **Retry**：only explicitly retryable transient events; retry budget=3 unless stricter domain budget; semantic/authority/security failures are non-retryable.
- **Timeout**：active nonterminal state must carry deadline; timeout routes to BLOCKED/EXPIRED/KILLED/REJECTED as appropriate.
- **Requalification**：expiry, revocation, source/version drift or rollback removes prior qualification and requires the corresponding admission path again.

|---|---|---|---|---|
|OFFER|CREATED|OFFERED|receiver/scope/TTL defined|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|ACCEPT|OFFERED|ACCEPTED|receiver identity and capability match|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|ACTIVATE|ACCEPTED|ACTIVE|permission token and budget valid|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
