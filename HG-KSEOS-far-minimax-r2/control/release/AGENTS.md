# AGENTS.md — Evidence/Release/DR Scope
Version: v2026.08.07-FINAL-r2
Applies to: evidence, checksums, readback, release candidate, DR and supersession paths.

EvidenceEnvelope is input to ReleaseDecision, not the decision itself. Hash/readback proves physical integrity only. Local final freeze is distinct from runtime/independent/production PASS. Human Product Authority owns release/replacement exceptions. Rollback targets must remain restorable and verified before supersession.
