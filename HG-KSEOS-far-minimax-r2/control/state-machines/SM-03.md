#### SM-03｜AgentSession

- **States**：NEW → CONTEXT_LOADED → PREFLIGHT → EXECUTING → CHECKPOINTED → REPORTING → ENDED → KILLED
- **Invalid transition**：reject event, preserve canonical state, emit finding/evidence; never coerce to nearest valid state.
- **Retry**：only explicitly retryable transient events; retry budget=3 unless stricter domain budget; semantic/authority/security failures are non-retryable.
- **Timeout**：active nonterminal state must carry deadline; timeout routes to BLOCKED/EXPIRED/KILLED/REJECTED as appropriate.
- **Requalification**：expiry, revocation, source/version drift or rollback removes prior qualification and requires the corresponding admission path again.

|event|from|to|guard|effect / failure branch|
|---|---|---|---|---|
|LOAD|NEW|CONTEXT_LOADED|context hash/source/AGENTS scope valid|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|PREFLIGHT|CONTEXT_LOADED|PREFLIGHT|tools/skills/permission admitted|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|EXECUTE|PREFLIGHT|EXECUTING|Harness effect token or read-only mode valid|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|CHECKPOINT|EXECUTING|CHECKPOINTED|progress/effect hashes captured|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|REPORT|CHECKPOINTED|REPORTING|stop/completion condition reached|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|END|REPORTING|ENDED|receiver packet/evidence complete|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
|KILL|EXECUTING|KILLED|security veto/no-progress/unauthorized effect|persist transition/evidence; unmet guard → INVALID_TRANSITION and no canonical mutation|
